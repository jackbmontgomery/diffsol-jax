# Benchmarks

All benchmarks compare diffsol-jax against [diffrax](https://github.com/patrick-kidger/diffrax) on
the same ODE problems, same tolerances (`rtol=atol=1e-8`), and the same hardware (Apple M-series).
Each benchmark picks the most appropriate diffrax solver for the problem type.

The tables below are generated by `benchmarks/run_all.py` — re-run it to refresh the numbers on your
own hardware:

```bash
uv run python benchmarks/run_all.py
```

## Forward solve

200 output times, wall-clock time per solve call after JIT warm-up.

<!-- BENCH:forward:start -->
| System                     | diffsol-jax | diffrax            | Speedup |
| -------------------------- | ----------- | ------------------ | ------- |
| Lotka-Volterra (non-stiff) | 0.59 ms | 2.18 ms (Tsit5) | 3.71x |
| Van der Pol μ=1000 (stiff) | 0.60 ms | 65.2 ms (Kvaerno5) | 109.40x |
<!-- BENCH:forward:end -->

BDF's variable-order stepping gives a large advantage on stiff problems. On non-stiff systems
explicit methods like Tsit5 are competitive.

```bash
uv run python benchmarks/bench_forward.py
uv run python benchmarks/bench_stiff.py
```

## Gradient / parameter fitting

500 Adam steps, `n_times=50`, Lotka-Volterra with Tsit45 and forward sensitivities.

<!-- BENCH:grad:start -->
| System                       | diffsol-jax           | diffrax               | Speedup |
| ---------------------------- | --------------------- | --------------------- | ------- |
| Lotka-Volterra (Tsit45+sens) | 194.4 ms / 500 steps | 3236.0 ms / 500 steps | 16.65x |
<!-- BENCH:grad:end -->

Both solvers converge to the same parameters. The speedup comes from diffsol running entirely in
compiled Rust (Cranelift-JIT'd DiffSL) — gradients avoid JAX's tracing overhead on the inner solver
loop.

```bash
uv run python benchmarks/bench_grad.py
```
